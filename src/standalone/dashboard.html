Firmware & OTA

Upload Firmware

Upload a compiled .bin to your library, then attach it to a device from that device's console to push the update.

Version: x.y.z or x.y.z-label (e.g. 0.1.1, 0.1.1-dev3). The label is a note — only its number affects order (0.1.1 < 0.1.1-dev1). It must match the firmware's PULSYNC_FW_VERSION / setVersion().

⚠️

The version string is trusted as-is — nothing reads it back from the .bin. If it doesn't match the code you actually compiled, you can push the wrong build or trigger an unintended downgrade to a device. Type it carefully: it's your responsibility that this version matches the firmware in this file.
